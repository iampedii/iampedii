## Hey, I’m Pedi.

I’m a **Lead Engineer in payment orchestration** based in Sydney. I work on payment APIs and processor integrations, with a focus on what happens when a payment times out or a processor goes down.

Outside work, I build networking tools and make Persian videos about programming and AI. I like showing how a tool fits into a real workflow and what you still need to understand when it writes the code for you.

### Projects

- [WhiteVPN](https://github.com/WhiteDNS/WhiteVPN) and [WhiteVPN Desktop](https://github.com/WhiteDNS/WhiteVPN-Desktop): VPN clients for Android, Android TV, and desktop.
